# Root Cause Analysis

## Method

1. Reproduce or trace the observed behaviour when practical.
2. Trace relevant control flow, state flow, and data flow.
3. Gather concrete evidence from code, logs, tests, configuration, or runtime behaviour.
4. Distinguish symptoms from causes.
5. Identify the narrowest proven cause that explains the behaviour.
6. Record uncertainty where the cause cannot be fully proven.
7. Do not jump to a solution before the causal chain is understood well enough to justify one.

## Output

- Observed behaviour
- Expected behaviour
- Evidence
- Causal chain
- Root cause
- Confidence/uncertainty
