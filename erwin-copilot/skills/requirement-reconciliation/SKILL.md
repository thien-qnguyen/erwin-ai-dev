# Requirement Reconciliation

## Method

1. Re-read the original request and extracted requirement checklist.
2. Map each acceptance criterion or required behaviour to the final implementation.
3. Link each requirement to available verification evidence.
4. Identify any deviation from the approved solution.
5. Identify any requirement that is only partially verified or not verified.
6. Distinguish implementation completeness from verification completeness.

## Output

For each requirement:

- status: satisfied / partial / unresolved
- implementation evidence
- verification evidence
- caveat, if any

Also report:

- deviations from the approved solution
- unresolved items
- unverified items
