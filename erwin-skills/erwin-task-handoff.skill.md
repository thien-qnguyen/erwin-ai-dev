# Erwin Task Handoff Skill

## Purpose

Create a compact, durable summary that lets a developer or a new AI session continue work without replaying the entire conversation.

## Use When

Use at task completion, before switching sessions, or when context has become long enough that continuity is at risk.

## Method

Capture only decision-relevant information:

- task goal and requirement checklist
- root cause or implementation rationale
- approved solution and important decisions
- rejected approaches when their rejection matters later
- changed areas/files
- tests added or updated
- verification completed
- known unverified areas
- remaining work or follow-up
- meaningful risks or caveats

Do not include secrets, credentials, private infrastructure values, or unnecessary project-sensitive detail in a reusable/public handoff.

## Output

A concise task-context document suitable for pasting into a new agent session or storing alongside development notes.
